# Лабораторная работа 3: Базы данных и бизнес-операции (Вариант 10)

## Предметная область: Грантовые конкурсы
Проект реализует REST API для управления конкурсами, проектными заявками, экспертными оценками и решениями о финансировании.

### Основные сущности:
1. **User** (`/api/users`) — пользователи системы (авторы и эксперты).
2. **GrantCompetition** (`/api/grant-competitions`) — грантовые конкурсы с бюджетом и сроками.
3. **ProjectApplication** (`/api/project-applications`) — заявки на конкурсы.
4. **ExpertReview** (`/api/expert-reviews`) — оценки экспертов.
5. **FundingDecision** (`/api/funding-decisions`) — решения о финансировании.

### Реализованные бизнес-операции (`/api/business/...`):
- Подача заявки с проверкой сроков проведения конкурса.
- Добавление экспертной оценки к заявке.
- Вынесение решения о финансировании с изменением статуса заявки.
- Закрытие грантового конкурса.
- Аудит и автоматическое отклонение заявок, превышающих бюджет конкурса.
